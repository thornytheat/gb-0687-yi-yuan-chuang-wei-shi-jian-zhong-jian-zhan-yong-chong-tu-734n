# 病床事件定义

id为事件号、patient为患者号、bed为床号，全部保留字符串及前导零。ward支持W1/W2或中文病区名；床号001–004属于一病区，101–104属于二病区。
time需带偏移，统一UTC。type支持admit、transfer、discharge、clean。同一患者按事件时间排序，同刻先出院、再转床、再入院。
占床段[start,end)，终点不重复计数。缺出院延长至observation_end并标记open。转床关闭前床并打开后床。没有入院的出院进入隔离。
同事件最高version采信；同版相互矛盾则全部隔离。完全重复和旧版单列。双占通过区间交集计算分钟，不直接删除来源事件。
清洁：discharge与transfer（transfer释放的是来源床from_bed）即把床位置入清洁。clean事件为清洁完成回报，按床匹配最近一次未回报的释放；
回报时刻纠正临时清洁窗，迟到回报仍完整回放并纠正可收治状态。无回报时按参数clean_minutes（默认30分钟）给临时窗，依据记为默认清洁。
清洁等待不计入任何患者住院时长：患者分段终点保持原出院/转出时刻，清洁窗不进M5日历与M6对账。
新患者在清洁结束前入住（释放时刻≤入院时刻<清洁完成时刻）：双方占床段全部保留并标review待复核，另在M4列EARLY早入住段，不删除任何占床段。
同一clean事件号重试按version去重，不新增清洁窗；同版矛盾全部隔离；找不到释放的回报按CLEAN隔离。
看板bed_board按观测终点给每床状态（可收治/清洁中/占用中/待复核/空床）与释放依据；GET /api/beds.csv导出，证据CSV追加EARLY行。
当地日历固定+08:00，午夜切分，分钟为Decimal。分段合计应等于日历合计，双占另外列明。迟到基于文件原始行序比较既有最大事件时间，晚到仍完整回放。
复核版本递增，旧版更新409。输入文件与参数纳入运行ID，内容不变重跑不增行。空值不可作为零时长。
